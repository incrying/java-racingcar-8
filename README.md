# java-racingcar-precourse

## 구현할 기능 목록

- [ ]  입력
- 자동차 이름 입력
    - 구분자(,)를 이용해 입력을 나눈다.
    - 입력이 공백이 아닌지 확인한다.
    - 이름이 중복되지 않는지 확인한다.
- 경주 횟수 입력
    - 숫자인지 확인한다.
    - 자연수가 맞는지 확인한다.

- [ ]  출력
- 최종 우승자를 출력한다.

- [ ]  자동차
- 입력된 이름을 저장한다.
    - 5자 이상이 아닌지 확인한다.
- 경주별 진척도를 저장한다.

- [ ] 난수 생성기
    - 0에서 9사이의 수를 생성한다.

- [ ]  경주 진행자
- 경주 횟수에 따라 라운드를 진행한다.
- 매 라운드가 종료되면 진척도를 출력한다.
- 자동차에 저장된 진척도를 참고해 우승자를 결정한다.
